# Порівняльний аналіз ORM та локальних БД для Android

## Список альтернатив
1. **Room** (Google) - Обгортка над SQLite, офіційна рекомендація.
2. **Realm** (MongoDB) - NoSQL база даних, об'єктно-орієнтована.
3. **SQLiteOpenHelper** - Нативний Android API (низькорівневий).
4. **SQLDelight** (Square) - Генерує type-safe код з SQL запитів.
5. **ObjectBox** - Ультрашвидка NoSQL база даних для IoT та Mobile.
6. **GreenDAO** - Стара, але колись популярна ORM для SQLite.

## SWOT-аналіз для Room
* **Strengths (Сильні сторони):** Compile-time перевірка SQL-запитів, інтеграція з LiveData/Flow, офіційна підтримка Google.
* **Weaknesses (Слабкі сторони):** Вимагає написання boilerplate коду (Entity, DAO), повільніша за чисті NoSQL рішення (ObjectBox).
* **Opportunities (Можливості):** Ідеально підходить для міграції існуючих SQLite баз, легке тестування.
* **Threats (Загрози):** Зростання популярності мультиплатформенних рішень (SQLDelight).

## Рекомендації щодо використання в production
Room є стандартом індустрії для Android розробки. Рекомендується для 90% додатків, що вимагають реляційної структури даних. Для KMP (Kotlin Multiplatform) проектів краще обрати SQLDelight, а для додатків з мільйонами записів у реальному часі — ObjectBox.
